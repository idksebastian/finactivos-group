# Por qué el texto del sitio no está justificado

El cliente pidió justificar los párrafos (alinear el borde izquierdo y el
derecho para que queden totalmente rectos). Se decidió no hacerlo porque, en
columnas de texto angostas como las que usa el sitio, justificar genera
espacios irregulares y grandes entre palabras -- se ve peor que el texto
alineado a la izquierda que ya tiene el sitio.

- `justificado-vs-no-justificado.png`: comparación lado a lado con el mismo
  párrafo real del sitio (Compra de sentencias), en una columna del mismo
  ancho que usan los párrafos actuales.
- `justificado-zoom-espacios.png`: acercamiento a la línea con el espacio
  más grande -- en este ejemplo, 19px de separación entre palabras contra
  los ~6px normales.
